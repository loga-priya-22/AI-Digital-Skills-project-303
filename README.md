# AI & Digital Skills Portfolio

A hands-on Python portfolio covering practical skills in artificial intelligence, productivity, retrieval-based applications, professional branding, defensive cybersecurity, version-control concepts, sales analytics, and career readiness.

## Project Modules

| Module | What it demonstrates |
|---|---|
| `01.ai_fluency.py` | Text tokenization, term-frequency vectors, cosine similarity, and structured prompt templates. |
| `02.ai_productivity.py` | Task prioritization with an Eisenhower-style matrix and meeting action-item extraction. |
| `03.ai_applications.py` | A lightweight retrieval-augmented generation (RAG) demo and text sentiment workflow. |
| `04.linkedin_profile_analyzer.py` | A scoring tool for profile sections and a before/after comparison chart. |
| `05.cybersecurity_toolkit.py` | Defensive password-strength estimation, SHA-256 integrity checks, and log review helpers. |
| `06.mini_git.py` | A small in-memory version-control simulator with staging, blobs, commits, and history. |
| `07.power_bi_dashboard.py` | Sales-data cleaning and generation of an executive-style analytics dashboard. |
| `08.career_essentials.py` | Career competency scoring visualized with a radar chart. |
| `HelloWorld.py` | A minimal Python starter example. |

## Supporting Data and Images

- `07.sales_raw.csv`: synthetic raw sales records used by the dashboard module.
- `07.sales_clean.csv`: cleaned sales output generated by the dashboard module.
- `07.sales_dashboard.png`: example sales dashboard image.
- `04.profile_improvement.png`: example profile improvement chart.
- `08.career_skills_radar.png`: example career skills radar chart.
- `requirements.txt`: Python package dependencies.

## Setup

Use Python 3.10 or newer. From the repository's main folder, install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run a Module

Run any module from the repository's main folder. For example:

```bash
python 01.ai_fluency.py
python 02.ai_productivity.py
python 03.ai_applications.py
python 04.linkedin_profile_analyzer.py
python 05.cybersecurity_toolkit.py
python 06.mini_git.py
python 07.power_bi_dashboard.py
python 08.career_essentials.py
```

Some modules create output files in the current working folder. The sales dashboard module reads `07.sales_raw.csv` and writes the cleaned dataset and dashboard image. The visualizer modules may regenerate their corresponding PNG files.

## Notes

- The sales data is synthetic and intended for demonstration.
- The cybersecurity module is for defensive learning and basic hygiene checks, not a substitute for a professional security audit.
- The RAG module is a lightweight educational example, not a production language model service.
